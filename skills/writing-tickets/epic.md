# Epic

Multi-sprint features, typically born from a PRD. Use on request only.

## Template
```markdown
# Summary
We are doing this feature so that we can support and enable the following.

# Motivation
Background on why we are doing this feature in the first place.

# Resources
- [PRD](https://link.to/prd)
- [Designs](https://link.to/designs)
- [Confluence](https://link.to/space)
```

## Refinement Check
Before creating, verify:
- [ ] Every resource is a URL a reader outside this conversation can open — no bare names, no local paths
- [ ] Code/file references, if any, follow [references/code-references.md](references/code-references.md)
